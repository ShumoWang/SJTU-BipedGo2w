# Go2W 拿放参考 V2：滚动约束修正及验证

**状态：理想圆轮无滑移筛查通过；动力学筛查与简单 PD 回放未通过。不得称为物理可行或直接可训练参考。**

## 修改

基于上一条 kneel 拿放参考。后腿 hip 设为零，使两后轮转轴平行；求后腿 thigh/calf，使轮心等高、轴线对齐，并在空载静态条件下把质心投影放到后轴上。拿放时仍调整腿部高度。

以差速运动方程积分后轴路径，联合拟合朝向和前向速度，停止直接复制人体路径的横向分量。按左右轮距分配轮速，同时补偿 thigh/calf 转动对轮胎绝对转角的影响。新参考 120 Hz、8.3 s，997 帧。保留上一版前腿关节动作（PCHIP 插值），但这不等于保留世界坐标系下的手部/物体接触目标。

## 量化结果

- 搬运段横向速度 RMS：0.296667 → 0.0000438 m/s。
- 全片横向残差峰值：0.00150 m/s；总平面接触速度残差峰值：0.00209 m/s。
- 两后轮相对机身方向接近 0°，理想轮心地面间隙误差小于 1e-6 m。
- 所有非轮关节在模型限位内；后腿最大参考速度约 2.69 rad/s。
- 根路径 RMS 改动 5.43 cm，最大 15.22 cm；终点误差 0.60 cm。
- 朝向 RMS 改动 35.1°，最大 61.3°。这是显著改动，必须在后续 HOI 世界坐标目标优化中处理。

通过条件为全片横向残差 < 2 mm/s、总平面残差 < 3 mm/s、理想轮接触高度误差 < 1 μm；这是离散参考的工程筛查，不代表轮胎物理精度。检测使用真实世界轮轴、MuJoCo 位姿差分及接触点 Jacobian，与上一轮原理相同。

## 动力学结果

空载、两后轮理想点接触，mu=0.8，使用摩擦锥内接方形及模型电机力矩上限，以线性规划最小化运动方程残差。167 个采样帧均未达到 1e-4 的逐分量方程残差容差。模型被动阻尼等计入，干关节摩擦未单独建模；因此这是指定假设下的筛查，不是对所有真实接触模型的不可行证明。优化残差目标混合广义力单位，不能把总残差解释为单一牛顿值。

力矩闭环回放从 3.5 s 初始化，随后仅施加关节 PD/轮速 PD，完全不重写根或关节状态。约 1.098 s 后根位置误差超过 0.5 m，停止。没有外部平衡力，没有物体负载，也没有前馈或专用平衡控制器；该失败不能证明所有控制器均失败。

## 下一步技术边界

几何上将空载静态质心放到轮轴正上方，不能保证加速/减速时平衡。需要把机身俯仰、质心/角动量、接触力、电机力矩与时序加入轨迹优化，再用平衡控制器闭环验证；同时维持拿放阶段的世界坐标交互目标。当前版本没有偷偷增加根部支撑或修改摩擦来获得假成功。
